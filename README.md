# 📋 Employee Task Management System



The Employee Task Management System is a full-stack web application designed to streamline task assignment, tracking, and workflow management in an organization.  

Built with React, Spring Boot, and MySQL, the system provides separate dashboards for admins and employees with secure authentication and robust role-based access.

## 🚀 Features



### 🔐 Admin Panel

- Add/update/delete employees  

- Create and assign tasks  

- Set task priority and deadlines  

- Track task progress with a dashboard  

- Monitor employee productivity



### 👨‍💼 Employee Portal

- View assigned tasks  

- Update task status (Pending → In Progress → Completed)  

- Add remarks/updates  

- View deadlines and priority clearly



### 🛠 System Features

- JWT-based secure authentication  

- RESTful API with Spring Boot  

- Global exception handling  

- MySQL relational storage  

- Reusable, modular React components  

- Good UI/UX for both admin and employees
